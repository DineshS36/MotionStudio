# MotionStudio

A modern motion design and programmatic video generation studio.

## Architecture

- **`motion-engine/`**: Remotion-powered programmatic video rendering engine, animation templates, and compositions.

## Getting Started

### Prerequisites

- Node.js (>= 20.19.0 or >= 22.13.0)
- npm / pnpm / yarn

### Running the Motion Engine

```bash
cd motion-engine
npm install
npm run dev
```

This starts the Remotion preview studio locally.

### Rendering Videos

```bash
cd motion-engine
npx remotion render
```
